# MyaK Biplane как Telegram Mini App

Игра запускается внутри Telegram как **Mini App** (веб-приложение в WebView). Специальный
нативный клиент не нужен: Telegram открывает тот же статический Blazor WASM-клиент, который
уже лежит на GitHub Pages, с поддержкой fullscreen, сенсорного управления и темы Telegram.

```
Telegram WebView ── HTTPS ──> GitHub Pages (клиент, Mini App)
                                  │
                                  └── WSS/HTTPS ──> MyaKBiplane.Server (Fly.io, SignalR)
```

## Что реализовано

- Подключён официальный SDK `https://telegram.org/js/telegram-web-app.js` в `index.html`.
  Вне Telegram он загружается, но не активируется — обычная игра в браузере работает как раньше.
- `wwwroot/js/telegram.js` вызывает `ready()`, `expand()`, запрашивает fullscreen и обновляет
  CSS-переменные `--tg-viewport-height` и `--tg-safe-*` при изменении viewport / safe area / fullscreen.
  Вертикальные свайпы включены в меню (иначе не листается выбор аппарата) и отключаются только в бою.
- Игра рассчитана на **горизонтальную ориентацию**. Пока телефон в портрете, показывается подсказка
  «Поверните устройство»; как только экран становится шире высоты, вызывается
  `Telegram.WebApp.lockOrientation()` (Bot API 8.0+, фиксирует текущую ориентацию). В обычном браузере
  используется `screen.orientation.lock("landscape")` в fullscreen, где это поддерживается.
- Тема приложения синхронизируется с `Telegram.WebApp.colorScheme` (светлая/тёмная), при этом
  сохранённый пользователем выбор в игре имеет приоритет. Цвет шапки и фона задаётся через
  `setHeaderColor` / `setBackgroundColor`.
- В меню показывается чип с именем пользователя Telegram (`initDataUnsafe.user`).
- Экранные стики и кнопки появляются на тач-устройствах и в мобильном Telegram:
  левый стик — движение/тяга, правый — прицел и огонь, кнопки — ускорение/рывок,
  перезарядка,катапульта (`E`), парашют и пауза.
- Кнопка «Назад» Telegram и закрытие с подтверждением включаются на экране боя.
- Нажатия кнопок сопровождаются лёгкой тактильной отдачей (HapticFeedback), где её поддерживает
  клиент.
- На коротких экранах (телефон в ландшафте) включается компактный масштаб: меньше шрифты, карточки,
  кнопки, стики и оверлеи. Меню ограничено по высоте и нормально прокручивается пальцем.

## 1. Настроить бота в BotFather

1. Откройте чат с [@BotFather](https://t.me/BotFather).
2. `/newbot` — создайте бота, получите токен. Он понадобится только если позже захотите
   серверную проверку `initData`; для самого Mini App токен не используется.
3. `/newapp` — создайте Mini App и выберите бота из шага 2.
4. Введите название и описание. По запросу загрузите иконку (512×512 PNG) и GIF-превью.
5. В поле **Web App URL** укажите адрес игры:

   ```
   https://ivanmyak.github.io/MyaK-Biplane/
   ```

   Адрес обязателен по **HTTPS** — Telegram не открывает Mini App по HTTP.
6. Включите кнопку меню бота: `/setmenubutton` → выберите бота → **Web App** → тот же URL.
   Тогда игра открывается кнопкой в чате с ботом.

Мини-приложение можно открыть и по прямой ссылке вида
`https://t.me/<bot_username>/<app_short_name>`.

## 2. Подтвердить сервер и CORS

Отдельных настроек CORS для Telegram **не требуется**: Mini App открывает тот же origin
`https://ivanmyak.github.io`, что и обычная страница GitHub Pages. Он уже разрешён в
`Cors__AllowedOrigins__0` на Fly.io (см. [`deployment.md`](deployment.md)).

Если вы публикуете Mini App на другом домене, добавьте его origin в CORS:

```powershell
& $flyctl secrets set Cors__AllowedOrigins__0=https://game.example.com --app myak-biplane-server
```

Проверьте, что сервер доступен по HTTPS и отвечает:

```
https://myak-biplane-server.fly.dev/health  →  {"status":"ok"}
```

Иначе меню откроется, но матч с ботом не запустится — клиент не считает физику сам.

## 3. Проверить в Telegram

1. Откройте Mini App через меню бота на телефоне (Android/iOS). Если телефон в портрете,
   появится подсказка «Поверните устройство» — разверните его горизонтально. Дальше ориентация
   фиксируется, и игра открывается сразу в ландшафте.
2. Убедитесь, что игра распахнулась на весь экран, тема совпадает с темой Telegram,
   а системные панели не перекрывают HUD (безопасные зоны учитываются).
3. Нажмите «Игра с ботом» — экран выбора аппарата должен прокручиваться пальцем, а кнопка
   «Начать бой с ботом» должна быть видна и нажимаема.
4. Проверьте компактный масштаб: шрифты, карточки, кнопки и стики помещаются на экране без
   перекрытий; на паузе легенда управления тоже листается.
5. Проверьте, что «Назад» в шапке Telegram возвращает в меню, а пауза/реванш работают.
6. Повторите проверку в светлой и тёмной теме Telegram.

В desktop-Telegram сенсорные элементы скрыты — там работает обычное управление клавиатурой
и мышью. Если на сенсорном ноутбуке стики не появились, проверьте, что браузер сообщает
`(pointer: coarse)`; принудительно их можно включить, добавив `telegram-mobile` к `<html>`.

## Ограничения и замечания

- `initDataUnsafe` используется только для отображения имени. Подлинность `initData` на сервере
  **не проверяется**: для этого нужно передавать `Telegram.WebApp.initData` на сервер и
  проверять HMAC с токеном бота. Если нужна авторизация пользователей/лидерборд — реализуйте
  проверку отдельно, токен храните только на сервере в secrets.
- Комнаты и матчи живут в памяти одной машины Fly.io (`--ha=false`). При перезапуске машины
  активные матчи сбрасываются.
- Некоторые старые клиенты Telegram не поддерживают часть методов SDK (`requestFullscreen`,
  `disableVerticalSwipes`, смена цвета шапки). Игнорирование ошибок в `telegram.js` делает
  Mini App работоспособным и без них.
- Рекомендуется горизонтальная ориентация: игровое поле 1600×900, на узком экране HUD теснее.

## Обновление не видно в Telegram / игра тормозит

Если в браузере по адресу GitHub Pages уже новая версия (проверьте номер внизу меню), а в Telegram
открывается старая — это почти всегда **адрес кнопки меню** или **кеш WebView**.

1. Проверьте, куда именно ведёт кнопка бота:

   ```powershell
   $token = "<токен_бота>"
   Invoke-RestMethod "https://api.telegram.org/bot$token/getChatMenuButton" | ConvertTo-Json -Depth 5
   ```

   Если там `*.trycloudflare.com` / `*.ngrok-free.app` — это адрес локального туннеля из тестов.
   Именно он объясняет и старый интерфейс, и сильные задержки: трафик идёт через туннель до вашего
   ПК. Верните кнопку на продакшн-адрес:

   ```powershell
   $url  = "https://ivanmyak.github.io/MyaK-Biplane/"
   $menu = @{ type = "web_app"; text = "Играть"; web_app = @{ url = $url } } | ConvertTo-Json -Compress
   Invoke-RestMethod "https://api.telegram.org/bot$token/setChatMenuButton" -Method Post -Body @{ menu_button = $menu }
   ```

   Или сделайте то же через BotFather: `/setmenubutton` → Web App → тот же URL.
2. Полностью закройте Mini App (смахните вверх / «Назад»), затем откройте заново. Telegram кеширует
   ресурсы Mini App по адресу — одного обновления страницы недостаточно. Если старая версия
   осталась, зайдите в **Telegram → Настройки → Данные и память → Память → Очистить кеш** и
   перезапустите Telegram.
3. Для гарантии можно добавить к URL кнопки параметр с версией, например
   `https://ivanmyak.github.io/MyaK-Biplane/?v=0.4.1` — он изменит ключ кеша и заставит Telegram
   скачать свежие файлы. После следующего деплоя параметр нужно будет увеличить.
4. Убедитесь, что Pages действительно пересобрался: откройте адрес в обычном браузере и сверьте
   номер версии внизу меню с последним деплоем в **Actions → Deploy client to GitHub Pages**.

## Диагностика задержек

Клиент использует **только WebSocket**. Раньше SignalR мог тихо откатиться на SSE или long polling,
если WebSocket блокировался WebView/прокси, — задержка взлетала до сотен миллисекунд без всякого
сообщения об ошибке. Теперь при недоступном WS подключение сразу завершается ошибкой, и на экране
появляется «Не удалось войти в матч».

В HUD боя рядом с кодом комнаты показывается `WS · Ping: <мс>` — время туда-обратно до сервера,
которое раз в 5 секунд измеряется вызовом метода хаба `Ping`. Как читать цифру:

- **20–60 мс** — сеть в порядке. Ощущаемая задержка управления объясняется тем, что клиент пока
  не предсказывает движение и ждёт снимок с сервера (до ~100 мс суммарно).
- **100–200 мс** — плохой маршрут до Fly-региона `fra` или перегруженный канал.
- **Ping — / ошибка подключения** — WebSocket не проходит. Проверьте, что Mini App открывается по
  HTTPS, а Fly-приложение не спит (`flyctl status --app myak-biplane-server`), и что в браузере в
  Network виден запрос `wss://myak-biplane-server.fly.dev/hubs/game`.

Чтобы убрать задержку полностью, нужен client-side prediction: локальная симуляция своего аппарата
с мгновенным откликом ввода и сверкой по серверным снимкам. Это следующий шаг после диагностики.

## Связанные файлы

| Файл | Что делает |
| --- | --- |
| `MyaKBiplane.Client/wwwroot/index.html` | Подключает SDK Telegram и `js/telegram.js`, viewport с `viewport-fit=cover`. |
| `MyaKBiplane.Client/wwwroot/js/telegram.js` | Инициализация Mini App, viewport/safe-area, тема, fullscreen, back-кнопка, haptics. |
| `MyaKBiplane.Client/wwwroot/js/theme.js` | Учитывает тему Telegram и красит шапку/фон клиента. |
| `MyaKBiplane.Client/wwwroot/js/game.js` | Сенсорный ввод и прицел, подключение стиков/кнопок. |
| `MyaKBiplane.Client/Pages/Play.razor` | Разметка сенсорных элементов, режим боя в Telegram. |
| `MyaKBiplane.Client/Pages/Home.razor` | Чип с именем пользователя Telegram, сброс режима боя. |
| `MyaKBiplane.Client/Services/GameServerClient.cs` | SignalR только через WebSocket, измерение RTT через `Ping`. |
| `MyaKBiplane.Client/wwwroot/css/app.css` | Fullscreen, безопасные зоны, стили стиков и кнопок. |
