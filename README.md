# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (PRD / GDD)
## Проект: MyaKBiplane (Кроссплатформенный 2D-шутер)

### 1. ОБЩАЯ АРХИТЕКТУРА РЕШЕНИЯ (SOLUTION)
Решение создается в среде **Visual Studio 2026 Professional** на языке **C# (.NET 8.0/9.0)**. Архитектура разделена на независимые слои для обеспечения кроссплатформенности и переиспользования кода.

*   **Название решения (Solution):** `MyaK-Biplane`
*   **Состав проектов в решении:**
    1.  `MyaKBiplane.Core` (Class Library) — доменная логика, физика, математика, ИИ бота. Не зависит от платформенных API и UI.
    2.  `MyaKBiplane.Shared` (Class Library) — общие ресурсы, конфигурации, файлы локализации (`.resx`) и сетевые DTO-пакеты для обмена данными.
    3.  `MyaKBiplane.Server` (ASP.NET Core Web API) — серверная часть, SignalR-хабы для онлайн-мультиплеера.
    4.  `MyaKBiplane.Client` (Blazor WebAssembly) — веб-клиент игры для браузеров (HTML5 Canvas).
    5.  `MyaKBiplane.Android` (.NET MAUI App) — мобильное приложение строго для ОС Android.
    6.  `MyaKBiplane.Tests` (xUnit Test Project) — проект для автоматического тестирования математики, физики и логики из Core-пакета.

#### Схема связей и зависимостей (Project References):
*   `MyaKBiplane.Core` ──► Ссылается на `MyaKBiplane.Shared`
*   `MyaKBiplane.Server` ──► Ссылается на `MyaKBiplane.Core` и `MyaKBiplane.Shared`
*   `MyaKBiplane.Client` ──► Ссылается на `MyaKBiplane.Core` и `MyaKBiplane.Shared`
*   `MyaKBiplane.Android` ──► Ссылается на `MyaKBiplane.Core` и `MyaKBiplane.Shared`
*   `MyaKBiplane.Tests` ──► Ссылается на `MyaKBiplane.Core`

### 2. ИГРОВЫЕ КЛАССЫ И БАЛАНС

#### Класс 1: Biplane (Биплан)
*   **Движение:** Быстрое, инерционное, предсказуемое. Физика полета и мертвых петель полностью копирует оригинальную JAR-игру *BT Biplanes* (расчет вектора через `Math.Sin`/`Math.Cos` с учетом гравитации).
*   **Механика атаки:** Стрельба пулями строго по прямой линии от положения носа самолета в момент выстрела.
*   **Частота стрельбы:** Фиксированная, 1.5 выстрела в секунду. Перезарядка отсутствует.
*   **Урон:** Для уничтожения противника требуется 4 попадания (25% здоровья за хит).
*   **Специальная способность:** Увеличение скорости движения (ускорение) на 5 секунд.

#### Класс 2: Pterodactyl (Птеродактиль с наездником)
*   **Движение:** Базовая скорость ниже, чем у Биплана, но обладает экстремальной маневренностью. Способен зависать в воздухе на месте и мгновенно менять вектор движения на противоположный.
*   **Механика атаки:** Метание копий. Направление броска выбирается игроком свободно мышью/тапом и не привязано к направлению тела существа. Имеется механика натяжения (зарядки): чем дольше удерживается кнопка атаки, тем выше урон и дальность броска, но тем дольше последующая перезарядка.
*   **Динамический баланс атаки:**
    *   *Минимальное удержание:* Перезарядка = 2 броска в 1 сек. Урон = требуется 8 попаданий (12.5% здоровья).
    *   *Максимальное удержание:* Перезарядка = 1 бросок в 5 сек. Урон = требуется 2 попадания (50% здоровья).
*   **Специальная способность:** Небольчий резкий рывок (дэш) в текущем направлении движения. Перезарядка способности — 2.5 секунды.

### 3. СЕТЕВЫЕ РЕЖИМЫ И ПЛАТФОРМЕННЫЕ ОСОБЕННОСТЬ

#### Платформа Android (`MyaKBiplane.Android`):
*   Игра с ботом (локальный ИИ из проекта `.Core`).
*   Локальный мультиплеер через Bluetooth P2P или локальную сеть Wi-Fi.
*   Онлайн-игра через Интернет (сервер `MyaKBiplane.Server`).
*   *Управление:* Наэкранный виртуальный джойстик и графические кнопки.

#### Платформа Web-Браузер (`MyaKBiplane.Client`):
*   Игра с ботом (локальный ИИ).
*   Онлайн-игра через Интернет (сервер `MyaKBiplane.Server`).
*   *Управление:* Клавиатура (движение) + Мышь (прицеливание и броски для Птеродактиля).

#### Сетевой функционал (SignalR + WebSockets):
*   Matchmaking (поиск случайного соперника).
*   Создание приватной комнаты и генерация ссылки-приглашения (инвайт-ссылка).
*   Внутриигровой список друзей для отправки прямых приглашений.
*   Синхронизация координат игроков и снарядов на частоте (Tickrate) не менее 30 Гц.

### 4. РЕСУРСЫ, ЛОКАЛИЗАЦИЯ И МЕДИА-ДАННЫЕ

#### Локализация (Мультиязычность):
*   Реализуется в проекте `MyaKBiplane.Shared` (папка `Localization/`) с помощью файлов ресурсов `.resx` (`Strings.resx` — английский, `Strings.ru.resx` — русский).

#### Графика и Звуки:
*   **Форматы:** Спрайты в `.png` или `.svg` (вектор). Звуки в `.wav` (эффекты) и `.mp3` (музыка).
*   **Хранение:** В `MyaKBiplane.Client` ресурсы размещаются в `wwwroot/assets/`. В `MyaKBiplane.Android` — в папках `Resources/Raw/` и `Resources/Images/`. Мастер-копии файлов подключаются в проекты как внешние ссылки (**Add as Link**).

### 5. АРХИТЕКТУРНЫЕ ТРЕБОВАНИЯ ДЛЯ РАЗРАБОТКИ КОДА (ДЛЯ ИИ)
1.  **IoU / DI (Инверсия управления):** Платформозависимый функционал (вибрация, вызовы JS API, Bluetooth) скрывается за интерфейсами в `MyaKBiplane.Core`, а реализуется в конкретных клиентах.
2.  **Архитектура движка:** Использовать разделение State Pattern для изоляции состояний «В меню», «Поиск матча», «Сессия игры».
3.  **Тестируемость:** Вся физика, тригонометрия полета и расчет урона изолируются в `MyaKBiplane.Core` для автоматического покрытия Unit-тестами (`MyaKBiplane.Tests`).
